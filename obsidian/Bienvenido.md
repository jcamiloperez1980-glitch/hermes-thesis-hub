# Bienvenido a tu Vault de Tesis

Este vault es parte de **Hermes Thesis Hub** 🎓

Aquí puedes organizar toda tu investigación doctoral con la ayuda de Hermes Agent.

## 📂 Estructura sugerida

```
📁 Hermes Thesis Hub/
├── 📁 00 - Diario/          # Notas diarias de progreso
├── 📁 01 - Literatura/      # Resúmenes de papers y artículos
├── 📁 02 - Metodología/     # Diseño, instrumentos, procedimientos
├── 📁 03 - Datos/           # Resultados, análisis, gráficos
├── 📁 04 - Escritura/       # Borradores de capítulos
├── 📁 05 - Referencias/     # Enlaces a Zotero y citas
├── 📁 06 - Defensa/         # Material para la presentación
└── 📁 Plantillas/           # Templates de notas
```

## 🚀 Cómo usar este vault con Hermes

Simplemente dile a Hermes en lenguaje natural:

- "Crea una nota con el resumen del paper **[[paper X]]**"
- "Busca en mi vault todas las notas sobre metodología"
- "Organiza mis notas en estructura de tesis"
- "Liga esta referencia de Zotero con mi nota del capítulo 2"

## 🔗 Integraciones

- **OpenAlex** → Busca papers → guarda resumen aquí
- **Zotero** → Referencias APA → enlaza desde aquí
- **Typst** → Escribe capítulos → exporta desde aquí
